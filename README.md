# Quizkampen Yellow 🟡

Quizkampen Yellow är ett nätverksbaserat frågespel skrivet i Java, inspirerat av det populära spelet Quizkampen. Spelet har ett eget grafiskt gränssnitt och låter två spelare utmana varandra i realtid över nätverket.

## 🚀 Funktioner
* **Spela online:** Utmana andra spelare över nätverket i spännande triviamatcher.
* **Grafiskt gränssnitt:** Ett användarvänligt och färgglatt GUI med valbara profilbilder (avatars).
* **Kategorier:** Välj mellan flera olika frågekategorier som *Film & TV*, *Nature & Environment*, *Science*, *Literature & Books* och *Food & Drink*.
* **Inbyggd chatt:** Kommunicera och skicka meddelanden till din motståndare direkt i spelet under matchens gång.
* **Returmatch eller ny spelare:** När matchen är slut kan ni smidigt välja att spela en returmatch eller leta efter en ny motståndare.
* **Tydlig poängräkning:** Spelet håller koll på rätt och fel svar via en visuell resultattavla efter varje rond.

## 🛠️ Teknologier
* **Språk:** Java 25
* **Gränssnitt:** Grafiskt gränssnitt (GUI)
* **Nätverk:** Stöd för onlinespel mot andra klienter över nätverk

## 📋 Förutsättningar
För att kunna kompilera och köra projektet behöver du följande:
* Java JDK 25 (eller senare) installerat på din dator.

## 🔧 Kom igång
Det enklaste sättet att köra spelet är att ladda ner koden och köra den via din föredragna utvecklingsmiljö (IDE).

1. Klona repositoryt till din dator:
   ```bash
   git clone [https://github.com/nhogblom/QuizkampenYellow.git](https://github.com/nhogblom/QuizkampenYellow.git)
Öppna projektet i till exempel IntelliJ IDEA, Eclipse eller VS Code.

Se till att projektets SDK/kompilator är satt till Java 25.

Kör programmets huvudklass (Main) för att starta klienten. (Om spelet kräver att en server körs separat, startar du serverklassen först).
